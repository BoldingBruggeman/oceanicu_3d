NSe Bio Boundary QA Report

Output of ocean-prep/cli/final_boundary_check.py — a pre-production sanity check for NSe’s own bio open-boundary pipeline (no3/po4/si/o2/dissic/talk), across models, scenarios, and generation methods (raw CMIP6, delta-change, direct bias-correction). Unlike the river/meteo checks, this one is NSe-specific (hardcoded to NSe’s own boundary output) — a clean run here says nothing about AMM7 or NS. See the Data Quality Checks guide for what this tool is, how to run it yourself, and how its scope compares to the other two.

This is a point-in-time report (generated 2026-10-25) — re-run the script for current data before trusting these specific numbers going forward.

Not the same thing as, and not a replacement for, NSe — Future Boundary Conditions: that page is the real scientific comparison (per-model/per-scenario plots, the bug-fix history behind the current values). This page is just an automated pass/fail check (plausible ranges, cross-model consistency, storage encoding) over the same underlying files.
