Root cause: rsus/rlus blow-up (investigated 2026-10-25)#

A real, confirmed numerical bug, not a data artifact. Production logs confirm rsus and rlus are both bias-corrected with method=qdm kind=* (multiplicative Quantile Delta Mapping). The multiplicative kernel, in ocean-prep/lib/bias_correction/algorithms.py’s _qdm_1d:

ratio = np.where(q_hist_at_fut != 0.0, future / q_hist_at_fut, 1.0)
return q_ref_at_fut * ratio

divides the raw future model value by the model’s own historical quantile value at the matched rank. The != 0.0 guard only catches an exact zero — not a numerically tiny one. At winter/high-latitude dawn and dusk, that historical quantile value can be a near-zero (but nonzero) float; dividing a modest future value by it produces a huge ratio, and multiplying by the reference quantile inflates it further.

Traced directly to one real grid cell (60.8°N, 15°E, GFDL-ESM4 historical, January 2014) — the value climbs smoothly for a few hours then explodes by 3-4 orders of magnitude in a single further step:

0.007 -> 0.29 -> 3857 -> 18196 -> 27563 W/m2   (4 consecutive hours, same cell)

Confirmed concentrated in historical for all 3 models, and additionally in CNRM-ESM2-1/ssp370 specifically (both sampled years). net_sw/ net_lw (bias-corrected as one direct composite, not from rsus/rlus at all) are not affected — their own domain mean stays a sane ~9 W/m². meteo.py’s default radiation_source (pseudo_tcc) reads rsds alone, not rsus, so this is not currently exposed by the production default — but "components" or "net" for a historical-inclusive run would read the broken files directly.

Fix direction: floor the divisor at a physically-meaningful epsilon instead of exact zero (e.g. np.where(np.abs(q_hist_at_fut) > eps, ..., 1.0)) — the same class of fix already applied once before for negative dissic values at a thin Baltic calibration window (see the comment above _DEFAULT_KIND in the same file). Not yet applied — this is a shared kernel used by every multiplicative-kind variable, reported here rather than changed unilaterally.
