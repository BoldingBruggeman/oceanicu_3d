CMEMS / CMIP6 Variable Mapping#

Overview#

This guide documents how biogeochemical variables are named across three systems:

  • CMEMS — Copernicus Marine Service products (OBC boundary conditions)
  • CMIP6 / ESGF — climate model output (scenario forcing)
  • FABM-ERSEM — the biogeochemical model variables inside GETM/ERSEM

Key unit difference#

CMIP6 uses SI units (concentrations in mol m⁻³), whereas CMEMS products typically report in mmol m⁻³. A factor-of-1000 conversion is required when using CMIP6 data as boundary conditions alongside CMEMS climatologies.

Ammonium (nh4) is not always available in CMEMS products. Total alkalinity (talk) and dissolved inorganic carbon (dissic) are generally absent from CMEMS daily/monthly files but are present in CMIP6 — SOCAT forcing must be kept for these variables until CMEMS provides them.

CMIP6 naming conventions#

Ensemble member identifier (ripf)#

IndexMeaningTypical value
rrealization indexfirst ensemble member
iinitialization indexfirst initialization method
pphysics indexfirst physics configuration
fforcing indexfirst forcing configuration

Example: r1i1p1f1 = primary ensemble member.

Loading via data-loader#

# Load CMIP6 biogeochemistry via ESGF (PANGEO mirror first, OPeNDAP fallback)
data-loader --cmip6 GFDL-ESM4/ssp126/no3/Omon/r1i1p1f1 \
    --domain -5. 15. 50. 65. --time-range 2015-01-01 2099-12-31 \
    --output gfdl_no3_ssp126.nc

# Search what is available on ESGF
data-loader --esgf-describe --source-id GFDL-ESM4 --variable-id no3
