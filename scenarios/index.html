Two different kinds of scenario content, kept separate:

Meteo Forcing

Atmospheric forcing for all regional ocean simulations: the raw CMIP6 archive and its bias-corrected counterpart, calibrated against ERA5. Model-agnostic – these diagnostics describe the forcing itself, not any particular ocean simulation.

Simulation Projections

Trend and period-change analysis of actual GETM simulation output run under a future SSP scenario – model-vs-itself (a reference period from the same run), not model-vs-observations. See Validations for the observation-comparison side.
